# 🧩 KanBan Board

A simple and intuitive **Kanban Board** built using **HTML, CSS & JavaScript** for task management and workflow visualization.

This project allows users to add, manage, and move tasks between different stages like _To Do_, _In Progress_, and _Done_ — using drag-and-drop interactions. Ideal for personal task tracking and learning DOM manipulation and event handling. :contentReference[oaicite:1]{index=1}

---

## 📌 Features

✔️ Add new tasks  
✔️ Drag and drop tasks between columns  
✔️ Clean layout using HTML & CSS  
✔️ Dynamic behavior using vanilla JavaScript  
✔️ Lightweight and beginner-friendly  

---

## 🛠️ Technologies Used

- **HTML5** – Markup & structure  
- **CSS3** – Styling & layout  
- **JavaScript** – Logic & dragging functionality
